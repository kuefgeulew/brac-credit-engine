## If Something Breaks
| Failure | Recovery Steps |
|---------|----------------|
| Charts not rendering | Refresh the page; ensure the browser window is at least 1024px wide. |
| Excel not downloading | Check browser pop-up blockers; verify the "Download" button isn't in a disabled state. |
| PDF not generating | Wait 5 seconds and click again; check the browser's downloads folder. |
| Page showing blank white | Hard refresh (Ctrl+F5 or Cmd+Shift+R) to clear the Vite cache. |
| Wrong borrower data showing | Return to the Dashboard and re-select the correct row. |
| Processing strip not animating | Ensure a firm and a valid PDF file are selected before clicking "Run Analysis". |
| Toast not appearing | Scroll to the bottom of the screen; toasts appear at the bottom center. |

## Post-Demo FAQ

**"Can it read our actual PDF statements right now?"**
Currently, the demo uses predefined mock data mapped to specific audit firms to showcase the workflow. The architecture is OCR-ready for future integration with live extraction engines.

**"Which audit firms are supported?"**
The system currently supports templates for A. Qasem & Co., Rahman Rahman Huq (KPMG), M/S Howladar Yunus & Co., Syful Shamsul Alam & Co., and Islam Afzal Parsons & Co.

**"How long does the analysis actually take?"**
In the demo, the processing is simulated to take about 6-7 seconds. In production, OCR and data extraction typically take 15-30 seconds depending on the document's complexity.

**"Does this integrate with our core banking system?"**
This version is a standalone portal. However, it is built with modern APIs, making future integration with core banking systems entirely feasible.

**"Is this Bangladesh Bank compliant?"**
Yes, the threshold parameters and scoring logic (ICRR, FSS, CRG) are designed to align with the latest Bangladesh Bank BRPD circulars.

**"Who maintains the regulatory thresholds?"**
System administrators or the Chief Credit Officer can manage and update the thresholds via the Settings page to reflect any new regulatory guidelines.

**"What happens to the uploaded documents?"**
In this demo, documents are processed client-side and not stored. In production, they would be securely routed through the bank's approved document management system.

**"When can this go to production?"**
Following successful UAT and integration with the live OCR engine and core banking APIs, the system can be deployed to production within the next quarter.
